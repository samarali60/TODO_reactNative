# 📱 ToDo App - React Native

A simple mobile application to manage your daily tasks using **React Native** and **Expo**.  
It allows users to add, view, complete, and delete tasks with an intuitive and clean user interface.

## ✨ Features

- 📝 Add new tasks with:
  - Task title
  - Task description
- 📃 Display a list of **active tasks** on the home screen.
- ✅ Mark tasks as completed.
- 🗑️ Delete tasks individually.
- 📄 View task details on a separate screen.
- 🔁 Bottom Navigation Bar with:
  - **Home**: Active tasks list.
  - **Completed**: List of completed tasks.


## 🛠️ Technologies Used

- **React Native**
- **Expo**
- **React Navigation**
- **Redux Toolkit** – state management
- **AsyncStorage** – local storage
- **React Native Vector Icons** – icons
